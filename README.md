# Zelda Save Manager

**One computer, multiple players. One player, multiple computers. — v0.1.0 Beta**

Zelda Save Manager is an independent fan-made Windows utility for *The Legend of Zelda: Ocarina of Time*, originally developed for Longshot and subsequently used with Squadala!, which retains the Longshot file structure. It was originally created so multiple children or family members could each have their own saves on one computer. It also supports accessing a player's profiles and saves from multiple Windows computers through a shared network folder. Randomizer tracking and hints are additional features.

## Two ways to play

### Multiple people on one computer

Create a separate profile for each child, family member, or player. Switch profiles by selecting a player's name so everyone can keep their own saves and supported settings without replacing someone else's progress.

### One person on multiple computers

Set up a shared network folder that each Windows computer can access to use the same player profiles and saves across those machines. This requires network folder configuration and access permissions; it is not automatic cloud syncing. Avoid using or changing the same save simultaneously on multiple computers, and keep backups.

## Features

- Create, edit, delete, and switch player profiles
- Manage separate game saves and supported settings for each player
- Access profiles and saves from multiple Windows computers using a configured shared network folder
- Configure supported Longshot and Squadala! multiplayer and randomizer settings
- Import compatible spoiler logs and track items and progressive upgrades
- Track Small Keys together in the grouped Small Keys tracker
- Reveal individual item hints in two stages: general area and specific check
- Use maps and a progression advisor to help plan your next steps
- Customize profiles with Zelda-themed icons and supported multiplayer options

**Compatibility:** Originally used with Longshot, then with Squadala! using the Longshot file structure. Both are supported targets based on these installations; compatibility with every version and configuration is not guaranteed. Standalone Ship of Harkinian has not been independently verified. Some features depend on the installed version and randomizer configuration.

## Installation

1. Download the Windows ZIP under **Assets** on the [Releases](../../releases) page.
2. Extract the entire ZIP into a folder.
3. Keep the extracted files together and launch Zelda Save Manager.
4. Point the application to your separately installed Longshot or Squadala! setup if prompted.
5. Create or select a player profile.

Some tracker functions require **Python 3.10 or newer with Tkinter**. Back up important saves before making changes. For network profile sharing, ensure each computer can access the same shared folder.

**No Zelda game ROMs, Nintendo game data, or Squadala!/Longshot executables are included in the prepared Windows distribution.** Obtain all required third-party software and game files separately and lawfully.
